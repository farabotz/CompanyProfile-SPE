This repository includes a lightweight pointer to the Taste Skill `design-taste-frontend` skill.

To fetch the full SKILL.md and blocks into this project, run:

```
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
```

Or consult the upstream docs at https://www.tasteskill.dev/ for the full ruleset.
